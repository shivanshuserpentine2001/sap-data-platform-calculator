Archiving & cold storage

Cheapest place for data you rarely touch
Tier / option Access pattern Per TB / month Your cold estate

Minimum-cost archive pattern

The cheapest SAP-native path is a tiered flow that leaves cold data on hyperscaler object storage and only reaches back through SAP metadata.

01
Hot data stays in HANA in-memory. Query performance is the reason you paid.
02
Warm data pushed to HANA Native Storage Extension. Same query engine, 4× cheaper per GB.
03
Cold data parked in SAP Data Lake (relational or files). Queries slower, cost drops 10×.
04
Archive via SAP ILM to hyperscaler object storage (S3 Glacier, Azure Archive, GCS Archive). Retrieval is hours-slow but cost is under $2 per TB per month.
05
Delete per ILM retention policy. The cheapest byte is the one you no longer store.
06

SAP ecosystem · services & pipelines

What each product does, what it plugs into

SAP HANA Cloud

Database engine

In-memory columnar database as a service. The physics layer of the SAP data estate. Every other product on this page runs on HANA under the hood.

Handles: relational · document · graph · vector · geospatial · time series · ML models.
Best for: real-time analytics, embedded app databases, semantic model foundation.
Scales with memory blocks · $ per 16 GB / month

SAP Datasphere

Data fabric

Modern data warehouse and virtual data layer. Federated queries, semantic modeling, data catalog, marketplace, all in one tenant.

Handles: replication · federation · virtual models · Analytic Model layer · Data Flow ETL.
Best for: new data warehousing, SAP + non-SAP unification, cross-source semantic layer.
Capacity units · storage + compute + base tenant

SAP BW/4HANA PCE

Legacy warehouse

Managed private-cloud edition of BW/4HANA. Same InfoObjects, aDSOs, Composite Providers, transformations you built on-prem, run by SAP.

Handles: classic BW modeling · queries · transformations · Process Chains.
Best for: preserving existing BW investment while exiting on-prem hardware.
Per-instance subscription · sized in TB, priced in FUE

SAP Business Data Cloud

Unified bundle

Launched Feb 2025. Bundles Datasphere, SAP Analytics Cloud, Databricks, and optionally BW/4HANA PCE under one CU pool with shared metadata and governance.

Handles: everything the components do plus Insight Apps, data products, cross-service governance.
Best for: large SAP estates wanting one commercial and one governance model.
Subscription-only · BDC CUs · minimum tenant is substantial

SAP BTP

Platform layer

The container everything else runs in. Integration Suite for iPaaS, Build for low-code apps, Work Zone for portals, AI Foundation for LLM services, Cloud Foundry runtime.

Handles: integration · custom extensions · workflow · APIs · IAM · auth.
Best for: connecting SAP to non-SAP, extending S/4 without modifying core.
CPEA credits · pay for what you consume across 95+ services

SAP Analytics Cloud

BI + planning

Consumption layer for everything above. Stories, dashboards, planning models, predictive scenarios, embedded analytics.

Handles: visualization · self-service exploration · planning · forecasting · predictive.
Best for: end-user reporting, financial planning, dashboards on SAP data.
Per user per month · BI, planning, and enterprise editions

Assumptions & rate card

Edit anything · numbers recompute live

Base rates are USD list-price bands from SAP Discovery Center, the Datasphere and HANA Cloud Capacity Unit Estimators, BDC service description guides, and public G-Cloud filings for BW/4HANA PCE. The region selector applies documented regional multipliers on top. Enterprise discounts of 20 to 45 percent are typical before RISE bundle credits.

Methodology & caveats. Rates are indicative list-price bands, before enterprise discounting, RISE bundle credits, and BTP Enterprise Agreement roll-ups. Regional multipliers reflect SAP local list-price patterns (SAP India typically 30 to 40 percent below US list, EU and APAC closer to parity). SAP quotes are individually negotiated, so use this tool for relative comparison and sizing conversations, not as a substitute for a signed order form. Compression assumptions reflect structured OLAP-shaped data on HANA and comparable columnar stores. Backup storage is 14x source per SAP guidance, priced against hyperscaler object storage.
